# Dataset Information

## Dataset
Sample Superstore Dataset

## Description
The dataset contains retail order-level information, including sales, profit, discounts, product categories, customer segments, and geographical regions.

## Source
Sample Superstore dataset.

The original dataset is stored locally in `Data/raw/` and is excluded from Git tracking to keep the repository lightweight.

## Important Columns
- Order Date
- Customer ID
- Segment
- Region
- Category
- Sub-Category
- Sales
- Quantity
- Discount
- Profit
